# luyen1

tạo web app nhỏ quản lý karaoke với HTML + JavaScript gồm các chức năng Nhập giờ vào – giờ ra → hệ thống tự tính số giờ / phút. Chọn giá phòng/giờ, điều chỉnh tên phòng thành VIP1, VIP2, VIP3, VIP5, VIP6, VIP7, VIP8, VIP9, VIP10, VIP1., VIP2., VIP3., VIP5., VIP6., VIP7., VIP8., VIP9., VIP10. Giá phòng VIP mặc định là 250000 còn phòng VIP. là 200000, thêm món (bia, nước, trái cây…). Tự động tính tổng tiền + thuế/phí (nếu có). Có nút In hóa đơn mẫu k80, in nội dung trong khu vực hoá đơn. Có hỗ trợ thiết kế mẫu in hoá đơn. Có lưu lại lịch sử hoá đơn.Phân nhóm món, chỉ in nội dung hoá đơn tính tiền, sử dụng bootstrap cho webform.
